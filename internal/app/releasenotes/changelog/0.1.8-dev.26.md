## Added

- **Pick the app's fonts from your installed families.** Appearance now lists
  the fonts on your machine for the app's UI and monospace faces, not just the
  bundled Inter and JetBrains Mono.
- **Grafana IRM alert groups** are emitted as feed items, with Alertmanager
  filtering pushed server-side so large instances stay responsive.
- **Pin an agent chat** into the Code view's session tree to keep it in reach
  while you work.

## Changed

- The New Session form preselects the agent `hive` would actually run, so the
  common case is one keystroke shorter.
- Quick terminal launchers are scoped to the session they run in rather than
  shared across every session.

## Fixed

- Pasting into a terminal pane is sent as a paste instead of one Enter per
  line, which no longer fires half a script on the way in.
- A terminal recovers from broker overflow in place; the view is no longer torn
  down and rebuilt underneath you.
