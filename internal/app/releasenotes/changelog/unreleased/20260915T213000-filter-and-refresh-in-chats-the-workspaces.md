**Filter and refresh in Chats**: the workspaces sidebar now opens on the same bar the Code view has -- a filter over workspace and chat names, a reload button, a + for a new chat, and a menu holding New workspace. Press / or ⌘F on macOS, Ctrl+F on Windows and Linux, to jump into the filter. Filtering a workspace by name keeps all of its chats, and opens it if it was folded.
