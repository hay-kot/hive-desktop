**⌘+ and ⌘- keep growing the terminal text** instead of stopping at the largest preset. The size is a pixel count now, stepped 2px a press between 8px and 64px, and Settings ▸ Terminal offers a stepper in place of the five named sizes. `terminal_font_size` still accepts `small`, `medium`, `large`, `xl` and `xxl` in `settings.yaml` and in its environment override, and a file that uses a name keeps using names.
