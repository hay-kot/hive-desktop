**First run ends with your agent, not a form.** Hive no longer asks you to name
a profile: a Default profile is there from the start, and connecting GitHub
fills it with the starter feeds. The last step hands you to your coding agent
in the built-in Hive workspace, which now comes with the app's MCP servers
wired in. It asks a few questions about how you work, then offers to set up
your profiles and feeds for you.
