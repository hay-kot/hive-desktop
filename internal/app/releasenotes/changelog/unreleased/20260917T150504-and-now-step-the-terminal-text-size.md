**⌘+ and ⌘- now step the terminal text size** instead of zooming the window, so the grid reflows and rewraps rather than growing a horizontal scrollbar. They walk the same sizes as Settings ▸ Terminal and the change persists; ⌘0 puts it back to medium. On Windows and Linux use Ctrl+Shift with the same keys from a terminal. Window zoom is gone from the View menu, since it never reflowed anything.
