**Split panes in Code.** A tmux window draws every pane where tmux lays it
out, and Code can split, select, resize, zoom and close them: ⌘D splits to
the right, ⌘⇧D below, ⌘⌥arrows move between panes, ⌘⇧↩ zooms, ⌘⇧W closes
the pane, and a drag on the border between two panes resizes them. On Linux
those are Ctrl+Shift+D, Ctrl+Shift+O, Ctrl+Alt+arrows, Ctrl+Shift+M and
Ctrl+Shift+Q. A window split from another tmux client now shows all of its
panes instead of one.
